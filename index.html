Open Charge Map verlangt seit Kurzem einen kostenlosen API-Key für Abfragen. Ohne Key findet die App keine echten Ladestationen. Key erstellen: map.openchargemap.io → Profil/Anmelden → API-Key. Der Key wird nur lokal in diesem Browser gespeichert.
